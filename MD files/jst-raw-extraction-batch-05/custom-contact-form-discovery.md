# Custom Tour / Contact Form Discovery

## Current Navigation Evidence
The live tour inventory exposes **Customize Your Tour** as a key entry point.

The Contact page provides office/contact channels but the retrieved version does not expose a complete custom-tour form schema.

## Required Retry
The AI agent must locate and inspect:
- Customize Your Tour destination/route
- any embedded/custom inquiry form
- dynamic form fields
- dropdown values
- conditional logic
- consent text
- success/error messages

## Migration Rule
Do not invent a custom-tour form based only on our future design specification. Preserve any useful current fields first, then improve the new form.
