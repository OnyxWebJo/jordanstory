# 07 — Final Content Production Framework
## Jordan Story Tours — EN + DE / SEO + AEO + GEO

This begins the production-content layer. Raw extraction remains the source of truth for commercial facts.

## Core Rule
Never change:
- price
- duration
- route
- inclusions/exclusions
- availability
- visa/border fees
- hotel category
unless verified against the migration dataset/business.

## Page Formula
Each important landing page should combine:
1. Search-intent H1
2. concise answer-first intro
3. Jordan Story narrative layer
4. practical travel information
5. related tours
6. destination context
7. FAQ where useful
8. internal links
9. booking/custom-tour CTA
10. structured data matching visible content

## EN/DE URL Strategy
English:
`/tours/...`
`/destinations/...`
`/travel-guide/...`

German:
`/de/touren/...`
`/de/reiseziele/...`
`/de/reisefuehrer/...`

Use reciprocal hreflang and x-default where appropriate.

## Story Experience Vocabulary
EN:
- Begin Your Jordan Story

DE:

- Wählen Sie Ihre Reise

German copy should sound natural. Do not translate “Story” mechanically everywhere.

## AEO/GEO Rules
- answer key questions early
- use clear entities: Petra, Wadi Rum, Amman, Dead Sea, Jerash
- state who/what/where clearly
- avoid unsupported superlatives
- use concise FAQ answers
- use Organization/TouristTrip/Breadcrumb/FAQ schema only when content qualifies
- build strong destination ↔ tour ↔ guide relationships
- include author/reviewer/update information on travel guides
