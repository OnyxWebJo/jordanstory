# Admin Dashboard — Final Scope

## Dashboard
- booking KPIs
- enquiries by status/source/tour/language
- revenue/value fields if business uses them
- popular tours
- upcoming travel dates
- conversion summaries
- content requiring verification

## Tours
CRUD:
- category
- EN/DE titles/slugs/content
- duration
- route
- destinations
- price / old price / currency / basis
- availability
- booking enabled
- includes/excludes
- itinerary
- gallery
- featured status
- SEO metadata
- FAQs
- publish status

## Destinations
EN/DE content, galleries, SEO, FAQs, related tours/guides.

## Bookings / Enquiries
- reference
- customer
- nationality
- email/phone
- travel date
- persons
- selected tour
- enquiry
- language
- source/UTM where available
- status: new/contacted/quoted/confirmed/cancelled/completed
- notes
- timestamps

## Custom Tours
Store request inputs separately from normal bookings and allow conversion into quote/booking.

## Transportation
Editable origin/destination/vehicle/capacity/price/currency/active/effective date.

## Media
Upload, migrated source URL, original, derivatives, alt EN/DE, caption, tour/destination relations, order, hash/dedup status.

## Blog/Guides
EN/DE editor, author/reviewer, updated date, SEO, related entities.

## Reports
- bookings by period
- bookings by tour
- nationality
- language
- lead source
- status/conversion
- custom-tour demand
- export CSV

## Settings
business name, address, email, primary phone, WhatsApp, social links, currencies, booking email recipients, default SEO, analytics IDs, language toggles.

## Roles
Super Admin / Admin / Content Editor / Booking Operator.
Use least privilege.
