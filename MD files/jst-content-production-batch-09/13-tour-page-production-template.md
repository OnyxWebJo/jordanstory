# Tour Page Production Template — EN + DE

This template governs all individual tour rewrites.

## 1. Search-Intent Layer
### EN
- SEO Title: `[Primary Tour Intent] | Jordan Story Tours`
- Meta description: route + duration + distinguishing value + CTA
- H1: exact understandable tour product

### DE
Use natural German search language:
- `Petra Tagesausflug ab Amman`
- `Jordanien Rundreise 7 Tage`
- `Petra und Wadi Rum Tour`
rather than literal English syntax.

## 2. Hero / Conversion Block
- Tour title
- verified duration
- verified starting price or Request Price
- destinations
- private/group status if verified
- Book / Enquire CTA
- WhatsApp CTA
- “Chapter” microcopy may be used but never obscure practical information.

## 3. Answer-First Summary
50–100 words answering:
- what is the tour?
- where does it go?
- how long?
- who is it suitable for?

## 4. Story Introduction
Short emotional paragraph connecting the route to the Jordan Story concept.

## 5. Itinerary
Each day/stop:
- clear heading
- route
- useful narrative
- realistic pacing
- no invented timing
- internal destination links

## 6. Includes / Excludes
Use only verified raw migration facts.

Never convert an optional activity into an inclusion.

## 7. Price
Admin-controlled database value.
Support:
- from price
- per-person / per-vehicle basis
- currency
- old price
- discount
- active date
- request-price mode

Discount percentage must be calculated from a valid old/current price pair.

## 8. Gallery
Automatically attach migrated tour gallery.
- preserve order
- use optimized WebP/AVIF derivatives
- retain source/original
- create useful EN/DE alt text
- avoid keyword stuffing

## 9. Practical Information
Only where verified:
- pickup
- approximate travel intensity
- walking considerations
- overnight structure
- meal notes
- border requirements
- seasonal issues

## 10. FAQ / AEO
3–6 questions specific to the tour.

Examples:
- Can I visit Petra from Amman in one day?
- Is the Wadi Rum Jeep tour included?
- How many nights are included?
- Can this itinerary be customized?

## 11. Related Story
Link:
- destinations on the itinerary
- related tour alternatives
- relevant travel guides
- custom-tour builder

## 12. Structured Data
Use schema only where appropriate and matching visible page content:
- BreadcrumbList
- TouristTrip / Product-like representation as technically appropriate
- FAQPage only when visible FAQs qualify
- Organization references

## 13. Translation Rule
German is localization, not word-for-word translation.
Protected commercial facts must remain identical across languages.

## 14. Publishing Gate
A tour cannot become `PUBLISHED` if:
- unresolved duration conflict
- unverified availability
- invalid discount
- missing price basis
- border/visa facts marked stale
unless the disputed field is hidden or explicitly approved by admin.
